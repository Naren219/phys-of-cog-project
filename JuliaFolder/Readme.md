If you want to run, download Julia (I used 1.12)
- Download vsc julia extension
- In vsc, `alt j + o` to open julia repl
- cd into the folder you have these files downloaded in
- make sure both the .toml files are in that folder
- With julia repl open, hit `]` to enter Pkg mode
- In Pkg mode, type `activate .` to create an environment
- Then type `instantiate` to activate all the dependencies
Once that's done, exit Pkg mode with `backspace`
